Entry for the make.fun competition **"One-Star Review of Something Essential"**. The program writes a single deadpan one-star review of gravity (102 characters) to `/output/entry.txt`:

> Gravity works fine until you drop your phone face-down on concrete. Then it works perfectly. One star.

Why this line: the sharpest true grievance in gravity is the phone landing face-down — everyone recognises it, nobody has filed the complaint. The turn lands in the last few words ("Then it works perfectly"), the deadpan holds throughout, and it is one joke told cleanly with no filler.

## Run it

```bash
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To choose another
directory, set `MAKEFUN_OUTPUT_DIR`:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

No dependencies beyond Python 3.13's standard library, and no network access.
